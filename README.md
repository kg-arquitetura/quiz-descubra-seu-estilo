# Descubra Seu Estilo

Quiz da **Katia Guerreiro Arquitetura** que revela o estilo arquitetônico de cada pessoa. São 12 perguntas; no final, a pessoa informa seus dados de contato, vê o resultado na tela e o recebe por e-mail.

## Tecnologias

- [React](https://react.dev/) 19
- [Vite](https://vite.dev/) 8
- Google Apps Script + Google Sheets (grava os contatos e envia o e-mail)
- GitHub Pages (hospedagem)
